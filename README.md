# Customer-Payment-Reminder-Email-Automation-using-Excel-VBA
End-to-end customer payment reminder automation using Excel VBA, Word, PDF generation, and Outlook email integration.

## 📌 Project Overview

An end-to-end Excel VBA automation solution designed to streamline the customer payment reminder process.

The project uses customer data from Excel to automatically generate personalized payment reminder letters, create individual PDF files, map the generated PDF paths back to Excel, and send personalized emails through Outlook with the corresponding PDF attachments.

## 🎯 Objective

To automate repetitive customer payment follow-up activities and streamline the process of document generation, PDF management, and email communication.

## 📊 Input Data

The Excel dataset contains:

* Customer Name
* Email ID
* Pending Amount
* Due Date

The corresponding PDF file path is stored in Excel for each customer.

## ⚙️ Key Features

### Personalized Letter Generation

VBA reads customer information from Excel and generates personalized payment reminder letters.

Each customer's letter is placed on a separate page.

### Individual PDF Generation

The generated letters are saved as individual PDF files using the corresponding customer name.

### Automated PDF Path Mapping

The VBA automation searches the selected folder for each customer's PDF and adds the complete file path to the corresponding Excel row.

### Outlook Email Automation

The solution uses customer email addresses and PDF paths from Excel to send personalized emails through Outlook.

Each email includes:

* Customer-specific greeting
* Relevant subject line
* Personalized email body
* Corresponding PDF attachment
